# ta-dam

A tiny macOS menu bar app that plays a custom sound every time your Mac wakes up. Open your Mac to a Ferrari engine, morning birds, or a song you love.

## How it works

ta-dam listens for the system wake notification (`NSWorkspace.didWakeNotification`, the official public macOS API) and plays your chosen sound. That's it. No network access, no accounts, no background daemons, no admin permissions. Your sounds never leave your Mac. The whole app is one Swift file you can read in five minutes.

## Install

Download the latest release, move `ta-dam.app` to Applications, and open it. The first time, macOS will warn that the app is from an unidentified developer — right-click it and choose Open. A sparkles icon appears in your menu bar.

Or build it yourself:

```sh
./build.sh
open build/ta-dam.app
```

Requires macOS 13+.

## Use

Click the sparkles icon in the menu bar:

- Pick a sound from the library (picking one previews it)
- **Search** to filter the library as it grows
- **Shuffle** to get a random sound on every wake, with **Shuffle from** to keep it to one category
- **Add sound…** to use any audio files you like (mp3, wav, m4a, aiff, caf) — select multiple at once
- **Test sound** to hear the current pick, and stop it anytime
- Hover a sound to preview or delete it; **Select** lets you delete several at once
- **Launch at login** is on by default so it survives restarts
- **Play sound on wake up** toggles it off without quitting

Your sounds live in `~/Library/Application Support/ta-dam/Sounds`. Subfolders become categories in the list — drop files there directly if you prefer.

## Starter library

Nature sounds and car engines. Generated with [eversince.ai](https://eversince.ai).

## Contributing sounds

PRs adding sounds to `sounds/` are welcome. Keep them short (2 to 4 seconds), pleasant at normal volume, and either generated by you or CC0 licensed.
